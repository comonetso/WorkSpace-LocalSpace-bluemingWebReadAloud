# 네이버 클로바 TTS API 테스트 안내

수정된 확장 프로그램을 테스트하기 위한 단계별 안내입니다.

## 1. 확장 프로그램 재로드

1. Chrome 브라우저를 열고 주소창에 `chrome://extensions/`를 입력합니다.
2. 개발자 모드가 활성화되어 있는지 확인합니다(오른쪽 상단의 토글).
3. 기존에 로드된 확장 프로그램을 찾아 "새로고침" 버튼을 클릭합니다.
   - 혹은 확장 프로그램을 제거한 후 "압축해제된 확장 프로그램을 로드합니다" 버튼을 클릭하여 프로젝트 폴더를 선택합니다.

## 2. API 설정 구성

1. 확장 프로그램 아이콘을 클릭하고 "설정" 또는 "Options" 버튼을 클릭합니다.
2. 설정 페이지에서 "고급 설정" 링크를 클릭합니다.
3. 네이버 클로바 TTS API 설정 섹션에서 다음 정보를 입력합니다:
   - Client ID: 네이버 클로바 API 계정의 Client ID
   - Client Secret: 네이버 클로바 API 계정의 Client Secret
   - API URL: `https://naveropenapi.apigw.ntruss.com/tts-premium/v1` (끝에 '/tts'를 붙이지 않습니다)
4. "Save Clova Settings" 버튼을 클릭합니다.

## 3. 음성 확인

1. 확장 프로그램 설정 페이지로 돌아가서 한국어 음성을 선택합니다.
   - 음성 목록에 "Clova 미진 (여성)" 또는 "Clova 지민 (여성)" 등이 표시됩니다.
2. 드롭다운에서 원하는 클로바 음성을 선택하고 "테스트" 버튼을 클릭합니다.
3. 음성이 정상적으로 재생되는지 확인합니다.

## 4. 실제 사용 테스트

1. 웹 페이지에서 텍스트를 선택합니다.
2. 선택한 텍스트에서 우클릭하고 선택한 글 읽기 메뉴를 선택합니다.
3. 음성이 정상적으로 재생되는지 확인합니다.

## 5. 디버깅 방법

문제가 발생하면 다음과 같이 디버깅할 수 있습니다:

1. `chrome://extensions/`로 이동하여 확장 프로그램 카드에서 "세부정보" 버튼을 클릭합니다.
2. "백그라운드 페이지 검사" 링크를 클릭하여 개발자 도구를 엽니다.
3. 콘솔 탭에서 다음 명령어를 실행하여 저장된 인증 정보를 확인합니다:
   ```
   await new Promise(resolve => chrome.storage.local.get(['clovaCreds'], resolve))
   ```
4. 오류 메시지가 있으면 콘솔에서 확인합니다.

## 문제 해결

1. "Failed to fetch" 오류가 계속 발생하는 경우:
   - manifest.json에 호스트 권한이 올바르게 추가되었는지 확인합니다.
   - API URL이 정확한지 확인합니다.
   - 인증 정보(Client ID, Client Secret)가 올바른지 확인합니다.

2. 인증 오류가 발생하는 경우:
   - 네이버 클로바 계정에서 API 사용 권한이 활성화되어 있는지 확인합니다.
   - API 호출 할당량을 초과하지 않았는지 확인합니다.

3. 음성이 재생되지 않는 경우:
   - 오디오가 차단되지 않았는지 확인합니다.
   - 개발자 도구의 네트워크 탭에서 API 호출 응답을 확인합니다.
